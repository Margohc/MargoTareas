# Mundialito de Canchitas

Proyecto Java con interfaz web para organizar un mundialito por descarte.

## Funciones

- Solicita la cantidad de participantes.
- Pide el nombre de cada participante.
- Forma equipos de 2 personas de manera aleatoria.
- Muestra los equipos sorteados.
- Genera partidos por descarte.
- Permite sumar puntos durante cada partido.
- El equipo con mas puntos al terminar el partido avanza.
- Muestra tabla de posiciones y campeones.

## Como ejecutar

Desde la carpeta `MundialitoCanchitas`:

```bash
javac src/Main.java
java -cp src Main
```

Luego abre:

```text
http://localhost:8080
```
